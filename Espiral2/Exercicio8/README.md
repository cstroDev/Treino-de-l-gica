# <Calcular total em compra de Açaí>

## Descrição

<Implemente um programa para calcular o total de uma venda de açaí a partir das quantidades compradas para cada tamanho: pequeno, médio e grande, sabendo que o valor do açaí é R$ 13,50, R$ 15,00 e R$ 17,50. O programa também deve receber o valor do cupom de desconto em porcentagem.>

## Exemplo

```
#Entrada:
<2
0
1
0>

#Saída:
<Total à pagar é R$ 44.5>
```
