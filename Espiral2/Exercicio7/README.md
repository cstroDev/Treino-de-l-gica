# <Parcelamento de Compra>

## Descrição

<Implemente um programa que retorne uma mensagem formatada com o valor das parcelas de uma compra, a partir do valor total da compra e da quantidade do parcelamento.>

## Exemplo

```
#Entrada:
<1500.5
10>

#Saída:
<Sua compra de R$ 1500.5 em 10x de
R$ 150.05 foi concluída>
```
