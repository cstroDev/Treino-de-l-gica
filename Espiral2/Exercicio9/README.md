# <Salário Líquido>

## Descrição

<Implemente um programa para calcular o salário líquido de um funcionário, a partir de seu salário base, do bônus mensal em porcentagem e do total de descontos em reais.>

## Exemplo

```
#Entrada:
<1000
10.5
349.50>

#Saída:
<Seu salário líquido é de R$ 755.5>
```
